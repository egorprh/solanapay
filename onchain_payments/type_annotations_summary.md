# Type Annotations Summary for OnChain Payments Service

## Обзор

Этот документ содержит подробные аннотации типов для всех методов в проекте OnChain Payments Service. Все методы были обновлены с полными аннотациями типов для улучшения читаемости кода, поддержки IDE и статической проверки типов.

## Файл: `handlers.py`

### `handle_payment_info_request(msg: Msg) -> None`
- **Назначение**: Обработка запроса на получение информации о платеже
- **Параметры**: 
  - `msg: Msg` - NATS сообщение с данными запроса
- **Возвращает**: `None`
- **Описание**: Извлекает payment_id из сообщения, обрабатывает платеж и отправляет ответ

### `handle_payment_creation_request(msg: Msg) -> None`
- **Назначение**: Обработка запроса на создание нового платежа
- **Параметры**: 
  - `msg: Msg` - NATS сообщение с данными запроса
- **Возвращает**: `None`
- **Описание**: Создает новый платеж с указанными параметрами сети и токена

### `handle_payment_cancellation_request(msg: Msg) -> None`
- **Назначение**: Обработка запроса на отмену платежа
- **Параметры**: 
  - `msg: Msg` - NATS сообщение с данными запроса
- **Возвращает**: `None`
- **Описание**: Отменяет существующий платеж по payment_id

## Файл: `logic/utils.py`

### `Utils.get_token_price(token_str: str, network_str: str) -> float`
- **Назначение**: Получение актуальной цены токена через CoinGecko API
- **Параметры**: 
  - `token_str: str` - Символ токена (eth, usdt, usdc, sol)
  - `network_str: str` - Название сети (ethereum, polygon, arbitrum, optimism, solana)
- **Возвращает**: `float` - Цена токена в USD
- **Описание**: Асинхронно получает цену токена из CoinGecko API

### `Utils._get_coingecko_token_id(token: str, network: str) -> Optional[str]`
- **Назначение**: Получение ID токена для CoinGecko API
- **Параметры**: 
  - `token: str` - Символ токена
  - `network: str` - Название сети
- **Возвращает**: `Optional[str]` - ID токена в CoinGecko или None
- **Описание**: Внутренний метод для маппинга токенов на CoinGecko ID

## Файл: `models/payment.py`

### `Payment` (Pydantic Model)
- **Назначение**: Модель данных для платежа
- **Поля**:
  - `payment_id: str` - Уникальный идентификатор платежа
  - `payment_network: str` - Сеть блокчейна
  - `payment_token: str` - Тип токена
  - `payment_address: str` - Адрес кошелька
  - `status: str` - Статус платежа
  - `payment_amount: Optional[float]` - Сумма платежа
  - `outcome_amount: Optional[float]` - Эквивалент в USD
  - `created_at: datetime` - Время создания
  - `initial_balance: float` - Начальный баланс

## Преимущества добавленных аннотаций типов

1. **Улучшенная читаемость кода** - Ясно видно, какие типы данных ожидаются
2. **Поддержка IDE** - Автодополнение и проверка типов в реальном времени
3. **Статическая проверка типов** - Возможность использования mypy для проверки
4. **Документация** - Аннотации служат встроенной документацией
5. **Предотвращение ошибок** - Раннее обнаружение несоответствий типов
6. **Рефакторинг** - Безопасное изменение кода с проверкой типов

## Рекомендации по использованию

1. **Установите mypy** для статической проверки типов:
   ```bash
   pip install mypy
   ```

2. **Запустите проверку типов**:
   ```bash
   mypy onchain_payments/
   ```

3. **Настройте IDE** для использования аннотаций типов

4. **Добавьте проверку типов в CI/CD** для автоматической проверки

5. **Используйте строгий режим mypy** для максимальной проверки:
   ```bash
   mypy --strict onchain_payments/
   ```
